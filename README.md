# FleetSignal

Caterpillar Smart Rental Tracking System (SRTS) — a hackathon project for tracking rented Caterpillar equipment: fleet dashboard, anomaly detection, alerts, demand forecasting, and rental lifecycle management.

The project lives under [`caterpillar-smart-rental/`](caterpillar-smart-rental/README.md). Start there for setup instructions, and see [`caterpillar-smart-rental/docs/`](caterpillar-smart-rental/docs/) for the product spec, API contract, and demo flow.
